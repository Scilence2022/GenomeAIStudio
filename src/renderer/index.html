Reviewer preferences

Enforced security invariants

These controls are enforced by the annotation ledger and cannot be disabled from the UI.

  • Separation of duties — a ChangeSet creator cannot approve its own proposal.
  • Explicit human review — autonomous proposals never mutate the genome directly.
  • Immutable proposal binding — approval is bound to the exact ChangeSet hash.
  • Target freshness — feature hash and annotation revision are checked before commit.
  • Evidence requirement — scientific qualifier changes require bounded evidence references.
  • Durable audit trail — each item in a batch retains an independent approval and commit receipt.
MCP identities and permissions are configured on the CodeXomics MCP server. This panel manages local human-review preferences, not API keys or server secrets.

About MCP Servers

The Model Context Protocol (MCP) enables advanced AI integration with external tools and data sources. When connected, MCP servers allow LLMs to:

  • Access real-time genome data and annotations
  • Perform advanced analysis operations
  • Interact with external bioinformatics tools
  • Provide more contextual and accurate responses
  • Access specialized databases and APIs

Note: MCP servers are optional. The application works fully without them.
